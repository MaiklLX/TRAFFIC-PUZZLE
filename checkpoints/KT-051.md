## Реализовано
- Поиск маршрута пропускает только активные рёбра дорожного графа.
- Направление движения по односторонним дорогам сохраняется.
- При расчёте маршрута берётся единый снимок позиций и скоростей машин.
- Движущийся транспорт добавляет небольшой штраф, медленная очередь — существенно больший.
- Штраф за пробку ограничен, чтобы не заставлять машины выбирать чрезмерно длинные объезды.
- Поиск маршрута использует индекс рёбер вместо повторного линейного поиска по всему массиву.
- На мобильных устройствах в портретной и альбомной ориентации используется одна схема: полноэкранная карта и нижняя горизонтальная панель инструментов.
- README приведён в соответствие с выбранным направлением: строгая 2D-камера сверху, Canvas 2D, мобильный-first, автоматический рост поселения.
