# KT-022 — Плавное следование автомобилей и безопасная дистанция

## Основа
- Предыдущая контрольная точка: KT-021.
- Репозиторий: `MaiklLX/TRAFFIC-PUZZLE`.
- Ветка: `main`.
- Коммит реализации: `f9e3277ba2c4ef039a6aa1c6b31fc07e3f826257`.

## Что изменено
- У автомобиля теперь есть текущая скорость и отдельная крейсерская скорость.
- Добавлено определение положения и направления автомобиля на текущем участке маршрута.
- Перед каждым обновлением движения вычисляются положения всех автомобилей.
- Автомобиль ищет впереди себя транспорт на той же полосе: учитываются продольная дистанция, боковое смещение и направление движения.
- При сокращении дистанции скорость плавно снижается; при освобождении дороги автомобиль постепенно разгоняется.
- Торможение быстрее разгона, чтобы уменьшить риск сближения.
- Контроль дистанции не должен останавливать машины, пересекающие дорогу поперёк на перекрёстке.
- Поиск маршрутов, распределение спроса по пунктам назначения, независимое появление машин и постепенное строительство дорог сохранены.

## Проверки и ограничения
- Код сохранён напрямую в `main`.
- GitHub Actions для коммита реализации: run `42797942790`; на момент создания этой КТ проверка ещё выполнялась.
- Следующий запуск Actions на коммите этой контрольной точки должен проверить TypeScript, production build и публикацию Pages.
- Ручной тест в браузере не выполнялся. Требуется проверить на сайте, что машины плавно замедляются друг за другом, не сталкиваются и не замирают из-за машин на пересекающих направлениях.
- Это базовая модель следования по геометрической близости и направлению, а не полноценная симуляция полос, очередей, приоритетов или сигналов светофора.

## Следующий этап

- После этого расширять правила потока и проверять дорожные решения на более насыщенном движении.
