# КТ-002 — браузерный прототип для ПК и телефона

**Репозиторий:** `MaiklLX/TRAFFIC-PUZZLE`  
**Ветка:** `main`  
**Последний проверенный GitHub-коммит исходников:** `bb251ea7d363bce619e4e420b6383b3bbdb77838`

## Содержимое этапа

- Основа Vite + TypeScript + Three.js.
- Изометрическая 3D-деревня с трассой, дорогами, домами, магазином, сараем, огородом, прудом, деревьями, заборами и фонарями.
- Две движущиеся машины на простых демонстрационных маршрутах.
- Камера: перемещение, вращение, масштабирование; ПК — мышь и клавиатура, телефон — сенсорные жесты.
- Адаптивные интерфейс и подсказки для портретной и альбомной ориентации.
- GitHub Pages workflow с проверкой типов, production-сборкой и публикацией.

## Статус проверки

- Файлы проекта повторно прочитаны из `main`.
- Успешная локальная сборка не заявляется.
- Результат GitHub Actions и доступность опубликованной страницы ещё требуют подтверждения.
- До подтверждения workflow не считать публичный браузерный адрес гарантированно активным.

## Что проверить на устройствах

1. ПК: панорамирование ЛКМ, вращение ПКМ, масштаб колесом, кнопки камеры.
2. Телефон: панорамирование одним пальцем, масштабирование/вращение двумя пальцами.
3. Портретная и альбомная ориентация.
4. Производительность, плавность движущихся машин, размер объектов, читаемость интерфейса.
5. Любые визуальные ошибки, зависания, вылеты или некорректное поведение камеры.
