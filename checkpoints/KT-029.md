# KT-029 — цельная геометрия разворота и жизнь деревни

- Дата: 10.11.2026
- Ветка: `main`
- Кодовый коммит: `fa7fccb5f86e5b78fc1c35a97b3107cb9e341995`

## Изменения
- Удалена эллиптическая «плитка» разворота.
- Разворот теперь рисуется как вытянутая петля из того же дорожного полотна: единая функция ленты дороги формирует обочину и асфальт, петля физически соединяется с концом подъезда.
- Добавлены ненавязчивые фоновые жители, которые гуляют по коротким дорожкам возле домов и магазина.
- Добавлен лёгкий анимированный дым из нескольких труб, чтобы деревня выглядела обитаемой.
- Движение фоновых жителей и дыма не влияет на транспортную симуляцию и не создаёт игровых препятствий.

## Проверки
- Требуется дождаться GitHub Actions для typecheck, production build и Pages deploy.
- Визуально проверить, что петля разворота совпадает с траекторией машин и не образует шва на стыке.
- Фоновая жизнь — первый слой атмосферы; далее можно добавить хозяйственную анимацию, птиц, сельские детали и реакцию поселения на транспорт.
