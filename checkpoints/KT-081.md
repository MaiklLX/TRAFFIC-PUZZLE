# КТ-081 — точный тип подключения и единый предварительный маршрут

## Найденная причина
Ранее первая выбранная точка сохранялась только как координата. При втором касании игра повторно вызывала `resolveRouteAnchor`, поэтому близкий въезд здания мог перехватить выбранную точку существующей дороги. Предварительный маршрут дополнительно запускал A* без флагов выбранного типа начального/конечного узла. В итоге предпросмотр и фактическая постройка могли использовать разные правила.

Также `drawRoutePreview` вызывал поиск пути из `render()`, а `render()` запускается каждый кадр симуляции. Это означало повторный A* поиск до 60 раз в секунду, даже без движения курсора.

## Изменения
- Сохраняется полный `RouteAnchor` с точкой, типом и названием; повторное распознавание первой точки удалено.
- Предпросмотр учитывает `building/network` типы обоих концов.
- Предпросмотр и постройка используют общую проверку сглаженного центра маршрута.
- A* предпросмотра кэшируется по двум привязкам и версии дорожной сети; пересчёт происходит только при изменении привязки или сети.
- Версия сети меняется при создании/удалении дороги и появлении новых зданий.

## Проверка
- Код и checkpoint отправлены в `main`.
- Требуется дождаться последнего GitHub Actions build + deploy.
- Ручное прохождение сценариев на реальном устройстве ещё не выполнено.

## Контрольные сценарии
- Объект → трасса.
- Объект → существующая дорога.
- Дорога → дорога, включая точку рядом с въездом здания.
- Проверка совпадения предпросмотра с построенной сглаженной геометрией.
- Проверка, что предпросмотр не вызывает повторный поиск без движения курсора.
