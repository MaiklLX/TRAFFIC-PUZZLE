# KT-003 — интерактивное строительство дорог

Дата: 10.11.2026  
Ветка: `main`

Последняя реализация редактора: `3911dfd530bfe1d90f598436e5d21f9b5d6ca9fe`.

## Реализовано
- Инструмент «Дороги» включает режим строительства и временно отключает перемещение камеры.
- Дорога рисуется перетаскиванием по игровому полю; координаты привязываются к сетке 1,5 игровых единицы.
- При быстром движении указателя промежуточные клетки автоматически заполняются.
- До фиксации показывается полупрозрачный предпросмотр.
- Отпускание указателя фиксирует сегменты дороги; стоимость — 25 монет за сегмент.
- Есть отмена черновика и удаление последней построенной дороги.
- Цель «Соедини деревню с трассой» засчитывается только если маршрут касается существующей деревенской дорожной сети и федеральной трассы.
- За первое выполненное соединение начисляется 300 монет; удаление последней соединяющей дороги отменяет награду и прогресс цели.
- Панель строительства адаптирована для узкого экрана.

## Проверка
- GitHub Actions на коммите с редактором подтвердил успешные `npm run typecheck` и `npm run build`.
- Публикация пока блокируется на `actions/configure-pages`: репозиторий ещё не включён в GitHub Pages. Попытка автоматического включения через workflow ранее завершалась `Resource not accessible by integration`.
- Для первого включения требуется один раз открыть Settings → Pages → Build and deployment → Source: GitHub Actions. После этого workflow сможет завершить публикацию.
- Отдельные быстрые коммиты запускали конкурирующие workflow; `cancel-in-progress` изменён на `false`, чтобы новые запуски не отменяли текущую проверку.
- После этого checkpoint нужно проверить новый запуск Actions до объявления сайта доступным.

## Тест-план
1. Открыть инструмент «Дороги» на ПК и телефоне.
2. Провести маршрут от существующей деревенской дороги к федеральной трассе.
3. Убедиться, что промежуточные сегменты заполняются, предпросмотр виден, стоимость списывается.
4. Проверить начисление +300 монет и прогресс 1/1.
5. Удалить последнюю дорогу и проверить откат прогресса/награды.
6. Проверить отмену черновика и выход из режима строительства.
