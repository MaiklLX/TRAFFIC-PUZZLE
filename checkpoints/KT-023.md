- Стили переключателя: `103a48ba13264ee94aaa7f8b21a7b9b70e1d9677`.

## Что сделано
- Машины размещаются на правой стороне направления движения с небольшим смещением от оси дороги — базовая модель правостороннего движения.
- При встречном движении на двусторонней дороге траектории проходят по разным сторонам полотна.
- У графовых рёбер теперь есть разрешённые направления прохода.
- Для проектируемой дороги в HUD добавлен переключатель:
  - «Двусторонняя» — разрешено движение в обе стороны.
  - «Односторонняя → по линии» — движение разрешено только в направлении, в котором игрок нарисовал проект от первой точки к последней.
- Алгоритм поиска маршрута учитывает направление ребра; если односторонний участок направлен против маршрута, путь через него не строится.
- При обновлении дорожной сети машины получают актуальные маршруты и снова размещаются на правой стороне своей траектории.
- Существующие статические дороги пока двусторонние.

## Проверки и ограничения
- TypeScript и production build прошли успешно на запуске реализации `42798449076`.
- Отдельные коммиты интерфейса запускают собственные проверки; итоговый Pages deploy необходимо проверить по последнему Actions run после этой КТ.
- Ручной браузерный тест не выполнялся.
- Это первая реализация полос: пока без полноценной геометрии полос на перекрёстках, разметки направления, обгонов и сложных перестроений. Смещение вычисляется по касательной маршрута; на острых поворотах его потребуется улучшить.
- Переключатель влияет на новые дороги; для уже существующих дорог режим по умолчанию двусторонний.
