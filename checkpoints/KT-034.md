# KT-034 — полезность дорог и выбор маршрута

- Дата: 10.11.2026
- Ветка: `main`
- Кодовый коммит: `a357995ef195cecb4b822bd11f495d4e89f19a72`

## Зафиксированное правило дорожной сети

- Дорога, подключённая только одним концом и не имеющая точки назначения на свободном конце, считается тупиковой веткой и исключается из маршрутов транспорта.
- Дорога, соединяющая две точки существующей сети, остаётся активной даже без здания на самой дороге: она может быть коротким транзитным соединением, альтернативой или способом разгрузить поток.
- Подъезды к объектам сохраняются как полезные ветви, потому что точки доступа объектов являются якорями сети.
- Учитываются въезд и выезд на федеральную трассу, доступность объектов и направление односторонних дорог.
- Изолированные дорожные циклы без связи с транспортными точками не считаются полезной сетью.

## Изменения

- В граф добавлен признак `active` для каждого участка.
- После построения графа выполняется очистка нецелевых листовых ветвей: тупики без назначения удаляются из транспортного графа, а циклы и связи между двумя узлами сети сохраняются.
- Поиск маршрута использует только активные участки.
- Выбор маршрута учитывает длину, класс дороги и текущую загруженность: медленно движущийся транспорт повышает оценочную стоимость участка. Это предварительная модель затрат, а не завершённая система топлива.
- Статус дорожной сети показывает количество активных участков.

## Что ещё не реализовано

- Топливо, заправочные станции и аварийная остановка при исчерпании запаса.
- Рогалик-выбор 3–5 зданий, случайное размещение, экономика и ресурсы.
- Полноценная модель пробок, очередей, пропускной способности и пересчёта маршрутов по фактическому времени поездки.

## Проверки

- Требуется GitHub Actions: typecheck, production build и Pages deploy.
- Требуется ручная проверка в браузере: тупиковая ветка без объекта не должна привлекать машины; дорога, подключающая две точки сети, должна становиться активной и использоваться, если маршрут выгоднее.
- Проверить отдельно односторонние соединения: физически связанная дорога не должна считаться доступной против разрешённого направления.
