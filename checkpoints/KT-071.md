# КТ-071 — оптимизация строительства дорог

Дата: 11.11.2026

## Проблема
При каждом кадре строительства менялся прогресс дороги и инвалидировался весь статический слой карты. В результате повторно рисовались ландшафт, вся дорожная сеть, сглаженные контуры и перекрёстки. По мере роста сети эта работа становилась всё дороже. Дополнительно граф дорог и геометрия перекрёстков использовали попарные проверки всех сегментов, а поиск узлов был линейным по уже созданным узлам.

## Что изменено
- Анимация строящейся дороги вынесена в лёгкий динамический слой поверх закэшированной карты.
- Полный статический слой теперь обновляется только при завершении строительства, изменении сети, перемещении камеры или изменении размеров холста, а не на каждом шаге анимации.
- Поиск потенциальных пересечений ограничен пространственными ячейками (broad phase); точная геометрическая проверка остаётся прежней.
- Поиск объединяемых узлов графа использует пространственные корзины вместо полного перебора узлов.
- Геометрия перекрёстков кэшируется и сбрасывается только при изменении дорожной сети; один и тот же кэш используется отрисовкой и транспортной симуляцией.
- При отмене последней дороги статический слой корректно помечается на обновление.
- Версия интерфейса: 0.69.

## Ожидаемый эффект
- Во время анимации прокладки дороги нет полного перерисовывания карты на каждом кадре.
- Пересчёт графа после завершения дороги проверяет только сегменты, чьи ограничивающие области пересекают общие пространственные ячейки.
- Поиск одинаковых узлов и группировка перекрёстков перестают сканировать весь накопленный список на каждой вставке.

## Изменения

- Устранение линейного поиска сегмента внутри источника: `95c0897f121b41bd1b490a47e5cabbedff296582`.
- Корректное обновление после отмены и версия: см. последующие коммиты.
