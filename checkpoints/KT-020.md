# KT-020 — Односторонние транспортные маршруты и поток с трассы

## Основа
- Предыдущая точка: KT-019.
- Репозиторий: `MaiklLX/TRAFFIC-PUZZLE`.
- Ветка: `main`.
- Итоговый коммит кода: `0b4a1d26a3170d04740de4809777d9a1747e15b9`.

## Что изменено
- Поиск маршрута заменён с BFS по числу рёбер на поиск кратчайшего пути по фактической длине дорожных участков.
- Демонстрационная поездка теперь имеет понятный цикл: въезд с левой стороны федеральной трассы → пункт назначения в посёлке → выезд на правую сторону федеральной трассы.
- Машины больше не разворачиваются на концах маршрута и не ездят туда-обратно по одной линии.
- Завершившие поездку машины удаляются с карты.
- Новые машины входят с трассы по временному интервалу; создание дороги само по себе не создаёт транспорт.
- При входе новой машины проверяется свободная дистанция у точки въезда, чтобы не создавать её вплотную к предыдущей.
- Дорожный граф включает только полностью построенные пользовательские дороги. Незавершённое полотно не становится доступным маршрутом заранее.
- Когда строительство завершается, граф перестраивается и активные машины получают актуальный маршрут с сохранением относительного прогресса.
- Цвета и скорости машин варьируются в небольшом диапазоне.

## Проверки
- Изменения сохранены в `main`.
- GitHub Actions должен подтвердить TypeScript, production build и Pages deploy для итогового SHA.
- Визуальная и игровая проверка в браузере не выполнялась. Нужна проверка, что машины действительно доходят до посёлка, покидают карту и не появляются слишком близко друг к другу.
- Это пока один демонстрационный пункт назначения и одна пара въезда/выезда, а не полноценная система спроса.

## Ограничения
- Нет выбора разных пунктов назначения, распределения транспортного спроса по зданиям, полос, очередей, светофоров и столкновений.
- При отсутствии связного пути новые поездки не создаются.
- Маршрут выбирается по длине, но пока не учитывает пробки, ограничения скорости и приоритеты.

## Следующий этап
- КТ-021: несколько пунктов назначения и маршрутизация разных машин по дорожному графу; привязать цели к существующим зданиям, не позволяя игроку строить здания или управлять экономикой.
- Затем добавить базовые интервалы движения и дистанцию между автомобилями, прежде чем вводить сложные правила перекрёстков.
