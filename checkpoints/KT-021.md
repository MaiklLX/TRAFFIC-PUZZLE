# KT-021 — Несколько пунктов назначения и распределение транспортного потока

## Основа
- Предыдущая точка: KT-020.
- Репозиторий: `MaiklLX/TRAFFIC-PUZZLE`.
- Ветка: `main`.
- Итоговый коммит кода: `da23f0051723e02a2ade323ebddd86f485996b02`.

## Что изменено
- Вместо единственного пункта назначения добавлен каталог из четырёх направлений: западный квартал, северный квартал, центральный квартал и магазин у трассы.
- Каждое направление привязано к узлу существующей дорожной сети; машины строят маршрут от въезда на федеральную трассу до выбранной точки, а затем — до выезда с противоположной стороны.
- Все маршруты рассчитываются по кратчайшей фактической длине пути на графе дорог.
- Поток распределяется между пунктами назначения по весам спроса: центральный квартал получает больший поток, чем северный.
- Для направлений заданы отдельные цвета автомобилей; добавлена компактная легенда в боковую панель.
- При изменении завершённой дорожной сети доступные пункты назначения пересчитываются, а активные поездки перестраиваются под свой пункт назначения.
- Если после изменения сети конкретный маршрут стал недоступен, соответствующая машина убирается из симуляции, а не едет по несуществующей дороге.
- Сохранено правило: строительство не порождает машины; новые поездки входят с трассы по интервалу и только если у въезда достаточно свободного места.
- Незавершённые дороги по-прежнему исключены из графа движения.

## Проверки

## Ограничения
- Точки назначения пока представлены узлами дорожного графа рядом с районами/объектами, а не полноценными подъездами к конкретным дверям зданий.
- Нет полос, очередей, светофоров, правил приоритета, столкновений и динамического перерасчёта из-за пробок.
- Спрос пока задан фиксированными весами; здания ещё не генерируют меняющийся спрос автоматически.
- Маршрутизация работает по существующему неориентированному графу; односторонние улицы и направления полос не моделируются.
