# KT-018 — Корректное распознавание узлов и независимых дорог

## Основа
- Предыдущая точка: KT-017.
- Репозиторий: `MaiklLX/TRAFFIC-PUZZLE`.
- Ветка: `main`.
- Коммит кода: `ddccc961b2d8ad81c8a7c7bf82cc693b06579ff8`.

## Что изменено
- Геометрия дорожной сети теперь сохраняет идентификатор исходной дороги для каждого сегмента.
- Сегменты одной и той же дороги больше не сравниваются друг с другом при поиске перекрёстков. Это исключает ложные узлы на сглаженных изгибах и местах, где соседние короткие сэмплы имеют общую точку.
- Реальные пересечения и примыкания разных дорог по-прежнему группируются в общий узел.
- Сборка источников дорог разделена на отдельные трассы: статические дороги и завершённые пользовательские дороги.
- Уточнено выражение радиуса скругления для читаемости и надёжности TypeScript.

## Проверки и ограничения
- Код сохранён в `main`.
- GitHub Actions запускаются после коммита; статус TypeScript/build/deploy нужно сверить по запуску для SHA выше.
- Визуальный тест в браузере не выполнялся. Не заявлять, что все диагональные T/X-перекрёстки визуально приняты.
- Группировка точек в радиусе 0.2 world units остаётся эвристикой. Очень близкие пересечения требуют отдельного визуального теста.
- Контур поверхности всё ещё строится выпуклой оболочкой; для сложных многолучевых перекрёстков позже может понадобиться локальная геометрия сопряжений.

## Следующий этап
- КТ-019: улучшить дорожные примыкания и маркировку, проверить сценарии диагонального T/X, ответвление и две близкие независимые дороги.
- После геометрии перейти к базовой логике назначения транспорта и маршрутов, не превращая проект в градостроительный симулятор.
