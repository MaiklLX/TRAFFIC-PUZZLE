# КТ-075 — точные примыкания без случайных наложений

## Причина
В КТ-074 допуск вокруг выбранного сетевого узла был круглым. Он разрешал проезжать рядом с точкой подключения через любой дорожный коридор, в том числе через соседнюю параллельную дорогу. Кроме того, проверка препятствий использовала исходные точки дорог, тогда как на карте они отображаются после сглаживания.

## Исправления
- Допуск примыкания теперь действует только у того конкретного сегмента, на который спроецирована выбранная точка.
- Соседние дороги в пределах того же радиуса не получают исключений и продолжают блокировать маршрут.
- Снижен допуск привязки касания к дорожной оси: игрок должен выбирать действительно существующую дорогу, а не область рядом с ней.
- Проверка коллизий использует сглаженную геометрию существующих дорог — ту же форму, которая отрисовывается на карте.
- Сохранены ограничения полей, сада, зданий и препятствий.

## Проверка
GitHub Actions запускает проверку сборки и публикацию после коммита. Ручная визуальная проверка перекрёстков и тестирование на физических устройствах не заявляются.
