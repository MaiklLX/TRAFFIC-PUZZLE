# КТ-078 — reuse route collision geometry

## Причина
После КТ-077 A* проверял корректную геометрию движения, но внутри каждой проверки заново собирал все статические и построенные дороги и повторно сглаживал их центральные линии. При плотной сети эта работа многократно повторялась для тысяч соседних ячеек и могла снова давать задержки при прокладке маршрута.

## Изменения
- Добавлен единый сборщик геометрии препятствий дорожной сети.
- В начале поиска A* сглаженные центральные линии существующих дорог собираются один раз.
- Один и тот же снимок геометрии передаётся в проверки каждого шага, упрощение маршрута и проверку сегментов.
- Для финальной проверки уже построенного кандидата создаётся отдельный актуальный снимок.
- Правила пересечения, запрет параллельного наложения, поля и препятствия не ослаблялись.

## Проверка
- Код и документация зафиксированы в main.
- Требуется дождаться GitHub Actions build/deploy.
- Ручная проверка игрового процесса и замер FPS на устройстве не выполнялись.
