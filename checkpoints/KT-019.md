# KT-019 — Чистое завершение разметки у перекрёстков

## Основа
- Предыдущая точка: KT-018.
- Репозиторий: `MaiklLX/TRAFFIC-PUZZLE`.
- Ветка: `main`.
- Коммит кода: `a7da047745558dbefd745e887ccba5a4eb0ded0b`.

## Что изменено
- Разметка центра дороги больше не рисуется сплошной линией через область перекрёстка.
- Перед отрисовкой центральных линий собираются актуальные узлы дорожной сети.
- Для каждого сегмента линии рассчитываются участки, попадающие внутрь зоны перекрёстка; эти интервалы вырезаются из разметки.
- Радиус очистки учитывает ширину подходящей дороги и небольшой запас, чтобы концы разметки не упирались в край асфальтовой площадки.
- Один и тот же путь применяется к прямым статическим дорогам и сглаженным пользовательским дорогам.
- Для строящейся дороги учитывается текущий процент готовности: разметка появляется постепенно вместе с полотном.
- Порядок рендеринга: дорожные полотна → разметка с вырезанными зонами узлов → поверхность перекрёстков.

## Проверки
- Код сохранён в `main`.
- Запуск GitHub Actions для кода: `42796468582`.
- Контрольная точка создаётся отдельным коммитом после изменения кода.
- Визуальная браузерная проверка не выполнялась. Не считать результат подтверждённым для всех форм перекрёстков до проверки диагональных T/X и близких узлов.

## Ограничения
- Сейчас центральная разметка намеренно прерывается внутри перекрёстка; отдельные стоп-линии, стрелки и приоритеты не добавлены.
- Вырезание использует круговую зону вокруг центра узла как практичное приближение.
- Сложные многолучевые пересечения всё ещё используют выпуклую оболочку поверхности.
