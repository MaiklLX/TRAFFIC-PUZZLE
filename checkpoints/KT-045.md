# KT-045 — выразительные автомобили и читаемый транспорт

- Дата: 10.11.2026
- Ветка: `main`
- Основа: KT-044

## Изменения

- Автомобили перерисованы в Canvas 2D с многослойным кузовом и градиентом окраски.
- Добавлены четыре колеса с дисками, нижняя часть кузова и мягкая контактная тень.
- Кабина разделена на переднее/заднее остекление, добавлены блики и линия крыши.
- Добавлены бамперы, дверной шов, ручки, фары и задние фонари.
- Внешние габариты шин сохранены компактными, чтобы не ухудшить размещение машин в полосе.
- Несколько пропорций кузова чередуются детерминированно по назначению маршрута, чтобы поток не выглядел копией одной и той же машинки.

## Проверки

- Ручная браузерная проверка не выполнялась.
- TypeScript, production build и Pages deploy проверяются GitHub Actions.
