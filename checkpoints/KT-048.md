# КТ-048 — Живая карта транспортного спроса

Дата: 10.11.2026

## Что изменено
- Панель «Точки назначения» больше не показывает условный фиксированный список из четырёх объектов.
- Список формируется из реальных семи транспортных назначений игровой карты: ферма, жилые дома и магазин.
- Для каждого объекта показывается его цвет, интенсивность спроса и фактический статус доступности.
- Статус «Связано» выставляется только если текущий граф дорог действительно позволяет построить маршрут от въезда на трассу через заправку к объекту и далее к выезду.
- После завершения строительства дороги и пересчёта графа статусы обновляются автоматически.
- Добавлен счётчик доступных объектов из общего числа.

## Зачем это нужно
Это первый игровой слой транспортной головоломки: игрок видит не абстрактное поле, а конкретные точки, которые сеть уже обслуживает или пока не может обслужить. Цвета объектов согласованы с цветами направляющихся к ним машин.

## Границы этапа
Пока это не полноценная система парных цветных районов Mini Motorways: происхождения поездок, рост города, ограниченный запас дорожных сегментов и динамические события будут отдельными этапами. Существующая логика демонстрационного потока сохранена.

## Проверка
Проверить GitHub Actions для коммита КТ-048. Успешная CI-сборка не заменяет ручное тестирование на телефоне.
