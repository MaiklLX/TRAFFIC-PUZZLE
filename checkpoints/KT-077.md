# КТ-077 — надёжный поиск маршрута

## Причина отказов
A* проверял диагональный шаг по двум соседним ортогональным клеткам. Если одна из них касалась существующей дороги, диагональное движение блокировалось, даже когда фактический диагональный отрезок мог безопасно пересечь дорогу. Дополнительно открытый список выбирался полным перебором на каждой итерации, что давало квадратичную стоимость поиска и преждевременный предел на сложной карте.

## Исправления
- Каждый переход A* проверяется как реальный отрезок с промежуточными пробами с шагом не более 0.22 мировых единиц.
- Удалена ложная проверка двух боковых клеток для диагонального шага: безопасность теперь определяется непосредственно геометрией движения.
- Существующие правила пересечения дорог и запрет параллельного движения по занятому коридору сохранены.
- Открытый список A* переведён на бинарную min-heap.
- Лимит поиска увеличен до 50 000 извлечений с отсечением устаревших записей и закрытием уже обработанных узлов.
- Финальная проверка сглаженного маршрута остаётся обязательной.

## Проверка
Результат сборки и публикации фиксируется GitHub Actions. Ручные игровые сценарии и тестирование на физических устройствах не заявляются.
