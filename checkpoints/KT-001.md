# КТ-001 / КТ-002 — первая браузерная сборка

**Проект:** TRAFFIC PUZZLE  
**Основная ветка:** `main`  
**Режим:** ранний браузерный прототип для тестирования на ПК и телефонах

## КТ-001 — фундамент

- Vite + TypeScript + Three.js.
- Адаптивная русскоязычная оболочка игры.
- Первая изометрическая 3D-сцена: долина, трасса, дороги, дома, магазин, сарай, деревья, пруд и автомобили.
- Камера с панорамированием, вращением и масштабированием.
- Панель задания, статистики и будущих инструментов.

## КТ-002 — визуальное оживление и мобильное управление

- Добавлены заборы, уличные фонари, дорожки, огород, камни и дополнительные детали окружения.
- Две машины двигаются по простым маршрутам, чтобы проверить восприятие живого трафика.
- Для телефонов ограничена плотность пикселей рендера и размер карты теней.
- Адаптируется поле под портретную и альбомную ориентацию.
- Добавлены отдельные подсказки управления для сенсорного экрана и ПК.
- Добавлены клавиатурные сочетания: `+` / `-` — масштаб, `R` — сброс камеры.
- Создан GitHub Actions workflow: проверка TypeScript, production-сборка и публикация GitHub Pages.

## Проверка

- Исходники и изменения сохранены непосредственно в `main` по явному разрешению пользователя для ускоренного тестирования.
- Автоматическая проверка `npm run typecheck` и `npm run build` поручена GitHub Actions; результат запуска необходимо проверить отдельно.
- До успешного завершения workflow и публикации Pages не считать браузерный релиз подтверждённым.

## Что тестировать

1. На ПК: перетаскивание ЛКМ, вращение ПКМ, колесо мыши, кнопки масштаба и поворота.
2. На телефоне: свайп одним пальцем, жест двумя пальцами, кнопки камеры.
3. Проверить портретную и альбомную ориентацию, прокрутку панели и отсутствие горизонтального скролла.
4. Обратить внимание на FPS, размер объектов, читаемость интерфейса и видимость деревни при первом открытии.
