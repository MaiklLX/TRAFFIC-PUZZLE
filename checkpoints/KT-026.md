# KT-026 — плавные развороты на тупиковых улицах

- Дата: 10.11.2026
- Ветка: `main`
- Кодовый коммит: `022a12e755e6aa112323839a058c61397a6b3073`
- Предыдущая точка: KT-025

## Что изменено

- В `offsetRouteToRightSide()` распознаётся почти обратный разворот маршрута (dot product < -0.82).
- Вместо резкого бокового излома между полосами строится дуга на 12 промежуточных точек. Автомобиль плавно меняет направление на конце улицы.
- Обычные повороты продолжают использовать ограниченный miter-offset; прямые участки не меняются.
- Исправлен расчёт длин сегментов после перестроения маршрута: длины теперь вычисляются по фактическому смещённому пути, включая новые точки дуги. Это синхронизирует скорость и положение машины с её нарисованной траекторией.

## Проверки и ограничения

- Изменение внесено в `main`.
- GitHub Actions должны подтвердить typecheck, production build и Pages deploy; результат проверяется отдельно.
- Ручная проверка поведения в браузере не выполнялась.
- Радиус разворота равен смещению полосы (0.36 world units): это компактный разворот внутри ширины улицы, не полноценная отдельная разворотная площадка.
