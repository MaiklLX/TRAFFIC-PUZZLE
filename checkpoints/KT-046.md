# KT-046 — Mobile-first playfield and touch controls

Date: 2026-11-10

## Goal
Prioritize the playable map on phones over decorative detail and desktop-style side panels.

## Changes
- On portrait mobile, the map now fills the available viewport below a compact header; the page no longer scrolls vertically during play.
- The desktop dispatcher panel is hidden on mobile so it cannot consume most of the playable area.
- The tool rail floats above the map as a compact touch-friendly control dock.
- Overview and road tools remain directly accessible; future/disabled tools are hidden on small screens.
- Zoom controls enlarged to 44px touch targets and moved above the bottom dock.
- Road planning HUD becomes a compact bottom overlay, keeping the active map visible.
- Safe-area insets are respected for modern phones.
- The initial/reset camera framing is mobile-aware: portrait phones use a taller, closer framing of the central village network instead of shrinking the entire wide map to fit its width. The user can pan and pinch to reach outer destinations.
- Landscape mobile keeps a full map with a vertical floating tool dock.

## Preserved
- Canvas 2D top-down rendering.
- Existing road graph, construction preview/build flow, direction selection, traffic simulation, pinch zoom, pan, and undo behavior.

## Validation
- GitHub Actions run must confirm typecheck, production build, and Pages deployment.
- No manual browser/device QA has been performed in this checkpoint.
