# КТ-063 — Оптимизация расчёта движения и HUD

Дата: 11.11.2026

## Реализация
- Кэширован список дорожных перекрёстков для расчёта приоритета движения. Он пересоздаётся только при перестроении графа дорог, а не на каждом кадре.
- В расчёте приоритета сначала применяется дешёвая проверка расстояния до перекрёстка; проекция маршрута вычисляется только для машин в зоне возможного влияния.
- Выбор машины, имеющей приоритет на перекрёстке, выполняется одним проходом без промежуточных фильтраций и сортировок.
- HUD трафика обновляется с частотой 4 раза в секунду вместо каждого кадра. При появлении или прибытии машин счётчики и доска направлений обновляются сразу.
- Удаление нескольких прибывших машин обрабатывается одной общей операцией обновления HUD.

## Сохранённое поведение
- Направления движения, маршруты, ограничения скорости и правила приоритета не менялись по смыслу.
- Учитываются занятые перекрёстки и приближающиеся машины; приоритет остаётся у уже находящейся на перекрёстке машины, иначе — у ближайшей подъезжающей.
