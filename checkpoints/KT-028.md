# KT-028 — цельное разворотное уширение и корректная траектория

- Дата: 10.11.2026
- Ветка: `main`
- Кодовый коммит: `69d4c3fe6403d7e252a368e7a6acb34227ccebae`
- Предыдущая точка: KT-027

## Что изменено

- Удалены отдельные круглые заплатки поверх готовой дороги.
- Разворотные уширения теперь вытянуты вдоль подъездной дороги и рисуются под дорожной сетью: основное полотно перекрывает их горловину, поэтому асфальт и обочина визуально сливаются в одну поверхность.
- Форма каждого уширения ориентируется по последнему сегменту реального подъезда к пункту назначения.
- Исправлена конечная касательная кубической кривой Безье: управляющая точка перед финишем теперь расположена так, чтобы автомобиль прибывал на обратную полосу с правильным направлением движения, а не с противоположной касательной.
- Разметка рисуется после дорожного полотна и не проходит через разворотную площадку.

## Проверка и ограничения

- Требуется проверить в браузере плавность манёвра и соответствие траектории вытянутому уширению на всех четырёх конечных точках.
- Визуальная геометрия пока приближённая 2D-модель; полноценная модель радиусов колёс и инженерных переходных кривых не реализована.
- Typecheck, production build и Pages deploy проверяются через GitHub Actions после коммита.
